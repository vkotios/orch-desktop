# Contributing to CHO Desktop

## Scope

CHO Desktop is a Tauri + Node host for Codex/Claude native conversations and orch
delegation. Prefer wrapping existing session-store and orch APIs over inventing a
second coordinator or persistence engine.

## Local checks

From the repository root:

```bash
npm ci
npm run typecheck
npm test
npm run build
```

Native Windows packaging (after Rust/MSVC/WebView2 are installed):

```bash
npm run native:build
```

`.runtime` is generated by `apps/desktop/scripts/prepare-runtime.mjs` and is not
committed. CI also runs a Windows `native-windows` job that stages the runtime and
runs `cargo test --locked`.

## Contracts and reviews

- Durable session behaviour is defined under `docs/contracts/`.
- Work-package status lives in `docs/work-packages/` and `docs/IMPLEMENTATION_STATUS.md`.
- Sensitive recovery/delegation changes keep independent review through orch when
  a qualified reviewer is available. Do not substitute paid routes or self-review
  as independent review.

## Release and public actions

Do not push, tag, change visibility, sign with new credentials, or publish a
release without explicit owner authority. Leave blocked AC rows with exact
instructions rather than lowering criteria.
